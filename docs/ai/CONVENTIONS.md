# Conventions

## Общие

- Не ломать существующий рабочий функционал без явного запроса.
- Не делать массовые рефакторинги без необходимости.
- Работать минимально инвазивно.

## Код

- Backend: Java, Spring Boot. Пакет: `com.example.integration`.
- Стиль: следовать существующему коду в проекте (контроллеры, сервисы, DTO, репозитории).
- Новые AI-провайдеры: добавлять клиент, реализующий контракт нейросети; регистрировать в NeuralClientFactory.

## Память и документация

- Перед задачей — читать все файлы в `docs/ai/`.
- Изменения в коде — обновлять `CURRENT_STATE.md`.
- Архитектурные решения — фиксировать в `DECISIONS.md`.
- После завершения задачи — краткая запись в `CHANGELOG_AI.md`.
- В память не добавлять: логи, stacktrace, временные рассуждения, промежуточные гипотезы. Только итоговое знание.

## Самокоррекция

- Если решение оказалось ошибочным: в DECISIONS.md пометить Superseded, описать новое решение; обновить CURRENT_STATE.md; привести код в соответствие.
