# Project Overview

## Цель

**AI Integration Service** — интеграционный сервис для связи любых внешних приложений с нейросетями (LLM, image/video и др.).

## Назначение

- Единая точка входа для запросов к разным AI-провайдерам (OpenAI, Yandex, Anthropic, Mistral, GigaChat, xAI, FASHN, Kling и др.).
- Управление доступами: клиенты приложений, API-ключи, подписки, лимиты.
- Аутентификация и авторизация (JWT, API Key) для внешних приложений.
- Фокус на backend; фронтенд в проекте есть, но не в приоритете.

## Масштаб

- Один backend-сервис (Spring Boot, Java).
- База данных: PostgreSQL.
- Внешние интеграции: AI-провайдеры, YooKassa (оплата).
